# Launch Checklist

State of the site as of 2026-07-27. Strategy: [Website_Strategy.md](Website_Strategy.md).

## Done

### Security
| Control | Implementation |
|---|---|
| Rate limiting | `api/lead.mjs` — 5 submissions per IP per 10 min, `429` + `Retry-After`. IP from left-most `x-forwarded-for` hop |
| Input validation | Allowlisted enums, regex on name/phone/email, length caps, `400` with failing field names. Never coerces — rejects |
| Sanitisation | Control chars and anything tag-shaped stripped, whitespace collapsed, hard length caps before any downstream use |
| API key handling | `LEAD_WEBHOOK_KEY` read from env only. Never returned, never logged, never sent to the browser |
| Body size limit | `413` above 8 KB, checked before parsing |
| CORS | Locked to `ALLOWED_ORIGIN`. No wildcard |
| Spam | Honeypot field. No CAPTCHA — avoids third-party cookies and the consent banner they'd force |
| Headers | CSP (no inline JS), HSTS preload, `X-Frame-Options: DENY`, `nosniff`, Referrer-Policy, Permissions-Policy, COOP |
| Endpoint hygiene | `/api/*` is `no-store` and `noindex` |

Verify with `node api/lead.test.mjs`.

### SEO
Canonical, OG and Twitter tags on all 13 pages · `LocalBusiness` JSON-LD on the
home page · `robots.txt` · `sitemap.xml` · semantic headings · descriptive alt
text · `theme-color`. All generated by `site/build.py` — re-run after adding pages.

### Traffic
Vercel Web Analytics, first-party and cookieless.

### Cookies
**The site sets no cookies and needs no consent banner.** Analytics is cookieless,
there is no third-party embed, no ad pixel, no CAPTCHA. Only `sessionStorage`
holds one flag so returning visitors skip the loading screen — same-origin,
non-tracking, outside the ePrivacy consent requirement.

This changes the moment a Meta or TikTok pixel is added. See below.

### Performance
Static HTML, no framework, no dependencies · immutable cache headers on
`/img/`, CSS and JS · lazy-loaded below-fold images with explicit dimensions ·
`prefers-reduced-motion` respected throughout.

## Before going live

1. **Replace placeholders** — `973XXXXXXXX` (phone + WhatsApp, every page),
   `info@qobban.com`, workshop address and hours, Instagram and TikTok URLs.
2. **Set `SITE` in `site/build.py`** to the real domain, then re-run `python build.py`.
3. **Set Vercel env vars** — `ALLOWED_ORIGIN`, and `LEAD_WEBHOOK_URL` +
   `LEAD_WEBHOOK_KEY` if leads should reach a CRM or inbox. Without the webhook
   the endpoint still accepts and logs, so nothing breaks.
4. **Enable Web Analytics** in the Vercel project (Analytics tab, one click).
5. **Generate the remaining 19 images** — see [../site/IMAGE_PROMPTS.md](../site/IMAGE_PROMPTS.md).
   `IMG-33` is the share image; until it exists, links preview with `IMG-01`.
6. **Favicon** — export the inline SVG logo mark at 32 / 180 / 512 px.
7. **Google Business Profile** — higher local-search impact in Bahrain than
   anything on-page. Do it before chasing rankings.
8. **Submit the sitemap** in Google Search Console.

## Deliberately not built

Each of these is real work, not an oversight — none is needed to launch.

| Not built | Add when |
|---|---|
| CMS | Someone other than a developer needs to edit copy. Static files are fine for one workshop's brochure |
| Cookie consent banner | A tracking pixel is added. Not before — it would be a banner consenting to nothing |
| Meta / TikTok pixel | Paid campaigns actually start. Adding one requires a consent banner and a privacy policy |
| Privacy policy | Before the first pixel or before collecting more than name/phone/message |
| Redis-backed rate limiting | Abuse appears in the logs. In-memory counters are per-instance — see the `ponytail:` note in `api/lead.mjs` |
| File upload to storage | The photo field currently isn't transmitted; clients send images over WhatsApp instead. Add S3/Blob when that friction shows |
| Arabic content | Copy exists. The RTL structure is already in place |
| Blog / case studies | There is content to publish. Empty sections read worse than absent ones |
| `cleanUrls` | Internal links are all `.html`; enabling it adds a redirect hop to every one |

## Known limits

- **Rate limiting is per serverless instance.** A distributed attacker gets
  roughly `limit × instances`. Correct for a brochure site's contact form;
  move to Upstash Redis if the logs say otherwise.
- **The photo upload is decorative.** The field exists but the file is not sent
  anywhere — the JS skips non-string form values. Either wire storage or remove
  the field before launch so it doesn't promise something it doesn't do.
- **`style-src` still allows `'unsafe-inline'`** because the pages use inline
  `style=` attributes. Much lower risk than inline script, which is now blocked.
